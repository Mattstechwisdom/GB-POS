# GadgetBoy POS v0.6.57

This release adds repair tutorial playback, polished automatic client acknowledgments, and an approval-first supplier cost review workflow.

## Highlights

- Save a YouTube, direct-video, or tutorial webpage URL on any repair catalog entry. The **Repair Tutorial** button opens a compact desktop player or responsive mobile player with play/pause, ±10-second seeking, volume, speed, fullscreen, and browser fallback.
- Automatically thank clients after the first diagnostic payment, ordered-part payment, or completed in-stock sale. Consultation bookings and meaningful appointment changes also generate branded messages.
- Automatic email events are idempotent and visible in Client Update History, including queued, sent, failed, and not-sent outcomes plus message previews.
- Inventory includes **Check All Prices**, **Check Selected**, and per-item **Check Price**. Review detected changes beside the previous cost, correct the proposed value if necessary, open the supplier page, then approve or skip.
- Supplier checks never change retail pricing or internal cost without explicit approval. Approved changes are audited and feed supplier/item-specific extraction learning.

The supporting Supabase migrations are additive and have been applied to the production project.
