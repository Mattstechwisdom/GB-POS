# GadgetBoy POS v0.6.79

## What changed

- Rebuilt Client Dropoff as a simple customer-facing intake form with live device category and device name choices.
- Client Dropoff now creates a zero-dollar Checked In work order without repair line items, then shows a hand-the-device-back confirmation screen.
- Added a discreet hold or double-click action on the GadgetBoy logo to return technicians to the Command Center.
- Fixed closed work orders reappearing in Command Center lists when an older workflow stage remained on the ticket.
- Added a synchronized technician task checklist beneath the EOD Activity drill-down.
- Kept desktop EOD within the full-screen workspace while retaining contained overflow for genuinely long lists.
- Styled scrollbars throughout desktop, tablet, and mobile layouts to match the POS theme.

## Platforms

- Windows x64 installer with automatic-update metadata
- Android universal APK
- Responsive web/mobile build
