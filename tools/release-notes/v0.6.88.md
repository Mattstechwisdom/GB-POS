# GadgetBoy POS v0.6.88

- Restores the native silent Windows update handoff so the installer keeps the existing install location, handles elevation when required, and relaunches GadgetBoy POS after installation.
- Removes the premature forced app exit that could close the update screen without applying the downloaded update.
- Important: install v0.6.88 manually once if upgrading from v0.6.87; automatic updates after v0.6.88 use the repaired updater.
