# GadgetBoy POS v0.6.71

- Repair Queue cards now lead with the checked-in device and model instead of a repair line item such as Diagnostic.
- Repair Queue cards show the client and reported problem with clean ellipsis truncation, plus compact work-order and activity details.
- Hovering Command Center work orders now opens complete device, client, problem, model, serial, status, and technician details.
- Active Work Orders, Checked In, full queue, and related Command Center work-order lists now use the same device-first labeling.
- Every active shared repair QR page now includes Request Repair Approval, Add / Update Promise, Technician Progress, and Testing In Progress.
- Technician Progress saves internal-only repair notes without emailing or texting the client.
- Approval requests include parts, labor, estimated total, expected date, and customer-facing details.
