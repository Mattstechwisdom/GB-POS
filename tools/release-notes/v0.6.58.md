# GadgetBoy POS v0.6.58

This corrective release tightens automatic repair checkout emails.

- Drop-off acknowledgments are sent only when the current checkout pays an outstanding diagnostic fee.
- Diagnostic repair line items are recognized as diagnostics, including PS5 diagnostic check-ins.
- Later labor payments cannot be mislabeled as diagnostic fees.
- Ordered-part acknowledgments require money applied to parts.
- Email amounts reflect only the diagnostic or part portion being acknowledged.
