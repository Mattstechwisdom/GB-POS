## GadgetBoy POS v0.6.83

- Fixes the Windows updater race that could report “failed to uninstall old files.”
- Captures the actual installer path returned by the completed download instead of reading a field that is absent from the update event.
- Starts a hidden handoff process that waits for the current GadgetBoy POS process to fully exit before launching NSIS silently.
- Relaunches GadgetBoy POS automatically after the update completes.

**Important:** v0.6.82 contains the broken handoff, so install v0.6.83 manually once. Updates after v0.6.83 use the corrected automatic process.
