# GadgetBoy POS v0.6.54

This release separates the ticket item-selection experiences and fixes repair catalog identity handling.

- Work orders now open a streamlined Repairs-style catalog picker.
- Sales now open a distinct Inventory-style picker with inventory search and filters.
- Linked ticket items show compact operational controls instead of duplicating Admin catalog fields.
- Parent-part repairs prompt for the exact inventory variant without creating duplicate repair entries.
- Repair sync preserves legacy catalog identities, so deleting an older unlinked repair no longer removes the link from the correct repair.
